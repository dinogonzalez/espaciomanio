# Actualización del perfil Instagram – Espacio Mañio

## Pasos exactos
1. Entra a tu perfil: Configuración → Editar perfil.
2. Cambia el nombre mostrado.
3. Pega la bio.
4. Actualiza la foto de perfil si quieres.
5. Agrega enlace si corresponde.
6. Marca la categoría como Product/service.
7. Crea highlights según guión abajo.

## Cambios aplicados
- Nombre fijado: `Espacio Mañio`
- Categoría: Product/service
- Bio lista para copiar
