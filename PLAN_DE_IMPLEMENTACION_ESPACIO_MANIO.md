## 🏡 2. Plan Paso a Paso para Retomar en Casa

Para continuar en el computador de casa sin perder ningún avance:

### Paso 1: Sincronizar el Repositorio Local
1. Abrir la terminal en la carpeta `Proyecto Parcela` en tu PC de casa.
2. Ejecutar:
   ```bash
   git pull origin master
   ```
3. ¡Listo! Todos los archivos organizados, fotos depuradas, gráficas y documentos aparecerán instantáneamente en tu computador.

### Paso 2: Publicar en Instagram y WhatsApp
1. Subir la imagen `post_lanzamiento_instagram.png` en el Feed de Instagram pegando el texto de `texto_publicacion_instagram.txt`.
2. Subir `story_lanzamiento_espacio_manio.png` en Historias de Instagram y Estados de WhatsApp.
3. Añadir música relajada/veraniega directamente desde la app de Instagram.

### Paso 3: Activar la Ficha en Google Business & Google Maps
1. Ingresar a [google.com/business](https://www.google.com/business/).
2. Crear/reclamar la ficha `Espacio Mañio - Paseos & Eventos Privados`.
3. Cargar las 8 fotos ordenadas de la carpeta `08-GMAP\Fotos_Para_Google_Maps`.

### Paso 4: Sitio web (pendiente, no publicar)

Actualmente no existe sitio web público activo. La maqueta local se conserva
para una futura revisión, pero no se debe habilitar GitHub Pages ni informar una
URL web hasta que se tome esa decisión expresamente.
