# Checklist Operativo – Espacio Mañio

## Antes del evento (2 horas antes)
- [ ] Baños limpios y con papel higiénico/jabón
- [ ] Parrilla limpia y con carbón/leña disponible
- [ ] Mesas y sillas limpias y acomodadas
- [ ] Piscina con nivel de agua correcto
- [ ] Areas verdes despejadas (basura, ramas)
- [ ] Estacionamiento despejado y con acceso expedito
- [ ] Luces exteriores encendidas si es atardecer
- [ ] Hielera con hielo disponible
- [ ] Botiquín de primeros auxilios listo

## Durante el evento
- [ ] Registrar hora de ingreso del cliente
- [ ] Verificar pago de seña / saldo pendiente
- [ ] Entregar llaves si corresponde
- [ ] Indicar ubicación de baños, parrilla y basureros
- [ ] Anotar número de personas para próximo cálculo
- [ ] Tomar 3–5 fotos sin intrusión (reutilizables luego)
- [ ] Pasar control cada 2 horas

## Después del evento (1 hora post)
- [ ] Inspección rápida: baños, piscina, quincho
- [ ] Registrar incidentes o daños
- [ ] Recoger residuos y ordenar áreas
- [ ] Anotar feedback del cliente
- [ ] Actualizar disponibilidad para próximas fechas
- [ ] Guardar fotos del evento para Instagram
